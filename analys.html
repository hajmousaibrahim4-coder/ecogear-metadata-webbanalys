Semantisk struktur och GTM

Jag använder semantiska element som header, nav, main, section, article och footer. För GTM har interaktiva element stabila id och klasser, till exempel #product-search, .js-product-link och .js-add-to-cart. Det gör det tydligt vilket element som ska mätas.

E-commerce-data i dataLayer

JavaScript pushar GA4-anpassade objekt till window.dataLayer. Produkt-events innehåller bland annat item_id, item_name, item_category, price, quantity, currency och value.

Lokal testning

Projektet körs lokalt med python -m http.server 8000 eller Live Server. GTM Preview används mot den lokala adressen. Därefter kontrolleras att events syns i Tag Assistant och GA4 DebugView.
